# DevOps Capstone
[![CI Build](https://github.com/harshalrrathod6109-ops/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/harshalrrathod6109-ops/devops-capstone-project/actions/workflows/ci-build.yaml)
This repository contains the CI/CD pipeline and DevOps automation for the Capstone Project.

## Project Description
A complete DevOps implementation including automated testing, linting, build pipelines, and OpenShift container deployments.

## Features
- **GitHub Actions Integration:** Automated linting with `flake8` and unit testing with `nose`.
- **Tekton Pipelines:** Automated tasks for testing and cleaning up workspace files.
- **OpenShift Deployment:** Continuous deployment setup for application builds and deployments.
